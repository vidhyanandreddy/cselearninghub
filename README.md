# CSE Learning Hub

A responsive academic resource web application built for B.Tech students to access study materials, previous year question papers, and technical learning resources from a single platform.

## 🌐 Live Demo

🔗 https://cselearninghub.netlify.app

## 📂 GitHub Repository

🔗 https://github.com/vidhyanandreddy/cselearninghub

## 📖 About the Project

CSE Learning Hub is a student-focused web application designed to simplify access to academic resources. The platform provides semester-wise study materials, previous year question papers, and technical content to support learning and exam preparation.

The application has been widely adopted by students across the college, serving as a primary resource hub for academic needs.

## ✨ Features

* 📚 Academic study materials
* 📝 Previous year question papers
* 💻 Technical learning resources
* 📱 Responsive design for mobile and desktop
* ⚡ Fast and user-friendly interface
* 🎯 Easy navigation and accessibility

## 🛠️ Tech Stack

## 🚀 Getting Started

```bash

```

### Run the Project

Simply open `index.html` in your browser.
